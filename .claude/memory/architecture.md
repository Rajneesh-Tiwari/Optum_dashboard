# Optum Dashboard - Architecture Reference

## Pages (Analytical Funnel)
1. **Population Overview** (`src/components/pages/PopulationOverview.tsx`)
   - KPIs: total members, avg age, avg PMPY, avg risk score
   - Feature Explorer: 7-group dropdown + feature selector -> dynamic chart
   - Supporting charts: age distribution, gender split, cost histogram
   - Reactive takeaways per feature group (7 population-level takeaways)

2. **AI Segmentation** (`src/components/pages/AISegmentation.tsx`)
   - 6 cluster cards (click to highlight)
   - Quick stats bar for highlighted cluster (includes risk score)
   - t-SNE scatter + cluster radar (both respond to highlight)
   - Reactive takeaways per highlighted cluster

3. **Cluster Deep Dive** (`src/components/pages/ClusterDeepDive.tsx`)
   - 6 clickable tabs, 9-column stat grid
   - PersonaCard (typewriter animation), CostHistogram
   - Utilization, SDOH, cost breakdown, LOB distribution charts
   - Reactive takeaways per active cluster

## Persistent: Insights Copilot (`src/components/layout/ChatDock.tsx`)
- Collapsible right panel, "Copilot" toggle with star icon
- Page-aware: different suggested queries per page
- Cluster-aware on Page 3: adapts to active cluster tab
- 27 hardcoded responses with citation sources
- Simulation animation (4 steps) + typewriter for responses
- Fallback for unmapped queries

## Key Components
- `src/App.tsx` - Main shell, lifted state (activeCluster, highlightCluster, selectedFeatureGroup)
- `src/components/layout/Stepper.tsx` - 3-step top navigation
- `src/components/layout/PageShell.tsx` - CSS fade transition wrapper
- `src/hooks/usePageNavigation.ts` - Page state, next/prev, arrow key support
- `src/hooks/useTypewriter.ts` - Typewriter animation hook

## Charts (all use full `echarts-for-react`, NOT echarts/core)
- `FeatureDistribution.tsx` - Dynamic: categorical, binary (% flagged), bucketed, or histogram
- `ClusterScatter.tsx` - t-SNE 2D scatter, highlight support
- `ClusterRadar.tsx` - 8-axis spider chart, highlight support, short legend names
- `CostHistogram.tsx` - Stacked bar by cluster, short legend names
- `BarChart.tsx` - Reusable bar chart
- `PieDonut.tsx` - Reusable donut chart

## Data Layer
- `src/data/ar_cardiometabolic_demo_data.json` - 500 members, generated by `generate_data.py`
- `src/data/ui_feature_metadata.json` - 7 feature groups (no member_id, no state)
- `src/data/chatResponses.ts` - 27 responses with sources, query matching, simulation steps
- `src/data/clusterPersonas.ts` - 6 persona narratives with typewriter text
- `src/lib/dataUtils.ts` - members, clusterStats(), avg(), membersInCluster(), feature helpers
- `src/lib/format.ts` - formatCurrency, formatPercent, formatDecimal, formatNumber
- `src/lib/echartsTheme.ts` - Registers `optumDark` theme (full echarts import)

## Feature Bucketing (in FeatureDistribution.tsx)
Predefined buckets for: age_at_pred, total_months, hifld_dist_uc_zp, pos_dist_ed_zp,
pmpy, total_allowed_amt, ip_allowed_amt, charleston_comorbidity_score_cci,
cnt_er_visits, cnt_pcp_visits, cardio_metabolic_risk_score, frailty_index

## 6 Clusters
1. At-Risk Baseline (red) - youngest, lowest cost, early hypertension
2. Unmanaged Metabolic Syndrome (orange) - 100% diabetes + hypertension
3. Advanced Heart Failure (yellow) - 35% readmission rate, highest acute spend
4. Diabetic Nephropathy / ESRD (green) - 80% ESRD, $90K+/yr per member
5. Rural SDOH Crisis (blue) - zero PCP, 45+ miles to UC, 100% HRSN
6. Frail Elderly Complex (violet) - CCI 4-9, highest frailty, 75-95 age range

## Build
- `npm run build` -> `dist/index.html` (single file, ~2MB)
- `dist/index.html` is committed to repo for non-tech distribution
- Works fully offline - double-click to open in any browser
